# Agentura

A VS Code extension: one interface for AI coding agents, with instruments the
stock clients hide — context in tokens, cost per turn, cache, limits, agent map.

Starts with Claude (via the Claude Agent SDK); other agents plug in through
adapters later.

**Status:** prototype approved (`prototype-v1`), implementation roadmap written. Nothing to install yet.
