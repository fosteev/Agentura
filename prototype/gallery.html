Вкладка «git»: варианты

04.10 · реализованы все — настройка «agentura.git.layout»живая страница

Третья вкладка правой панели, изменения | git | агенты, по образцу правой панели GitKraken, но в ширину 360 px. Работает на git (рабочее дерево и индекс), а не на ленте: видны и правки через Bash, и твои ручные. Чтобы она не дублировала «изменения», файлы, которые правил агент в этой сессии, помечены фиолетовой точкой, а чип «● агент N» оставляет только их. Строка файла: имя цветом статуса git, папка, +/−, буква (M / U / A / D). На наведении — открыть, отменить изменения, в индекс / из индекса. Внизу коммит: заголовок со счётчиком до 72 символов, ✦ (сообщение пишет агент по индексу), описание, amend, «и push», ▾ (коммит и push / в новую ветку / stash). Первый кадр — один репозиторий, остальные — рабочая папка queue/ с тремя репозиториями: board (ветка ↑1), ws-client (ветка ещё не в origin), infra (чистый, ↓3). Что сравнивать в мультирепо: видно ли сразу, где что изменено и на какой ветке, и куда уйдёт коммит.

Каждая вкладка чата помнит свою ширину, свёрнутость и вкладку панели. Узкая вкладка (< 700 px) не меняется: чат | ход | агенты в шапке.

Свёрнутая панель — полоса 32 px (вариант B, выбран 02.10): значки «ход» и «агенты» с бейджами, клик по значку разворачивает панель на этой вкладке, внизу — «показать панель».

Несколько агентов

живая страница · итог

Основной запустил четырёх субагентов параллельно. В ленте — группа «agent ×4»: строка на каждого с текущим вызовом, токенами, временем и ■; готовые показывают итог одной строкой, упавший — ошибку. Вкладка панели «агенты» — список агентов (основной, субагенты, фоновые задачи, токены хода) и под ним детали выбранного: промпт от основного, его ход по времени, транскрипт и остановка. После хода группа остаётся в ленте с итогами, а в деталях — что агент вернул основному.

Тултипы и язык

Тултипы элементов управления

новое · 02.10живая страница

Вместо серого системного title — подсказка в стиле hover-виджета VS Code (цвета editorHoverWidget) на всех кнопках чата, боковой панели и настроек. Появляется через 0,5 с; соседние кнопки после первой — сразу. Встаёт под кнопкой, у нижнего края — над ней, к краям панели прижимается; уголок смотрит на кнопку. Вторая строка — приглушённая (время данных, сброс), клавиша — плашкой справа. Показывается и при переходе по Tab, прячется по Esc, клику, скроллу. На живой странице — наведи на любую кнопку.

Язык интерфейса

новое · 02.10живая страница

Настройка agentura.language в разделе «Внешний вид»: как в VS Code (по умолчанию) / Русский / English. «Как в VS Code» — русский, если VS Code на русском, иначе английский. Смена применяется после перезагрузки окна (уведомление с кнопкой). Заголовки команд и описания в Settings UI VS Code всегда следуют языку самого VS Code.

Боковая панель

Вид списка сессий

новое · 02.10живая страница

Три настройки в разделе «Вид»: agentura.sessionList.view — строк на сессию (подробно / компактно / плотно; ещё кнопка ☰ → ≡ → ≣ в заголовке «Сессии»), .context — колонка контекста («173k ctx»), .time — колонка времени. Обе колонки по умолчанию включены, фиксированной ширины и выровнены вправо — у всех строк в одну линию. Ходы и цена у однострочных — в подсказке строки. Справа на картинке — сколько сессий из 18 видно без прокрутки.

Вид верха боковой панели

новое · 02.10живая страница

Настройка agentura.sidebar.top в разделе «Вид» — сколько места над списком сессий занимают аккаунт, лимиты и «Новая сессия»: подробно (как сейчас, ~380 px), компактно (~210 px), плотно (~105 px). В компактном и плотном «Новая сессия» — кнопка ＋ в заголовке «Сессии». Вид списка сессий настраивается отдельно. Справа на картинке — высота верха и сколько сессий из 18 видно без прокрутки. По умолчанию пока «подробно» — остальные экраны не меняются.

Единственное содержимое боковой панели: аккаунт, лимиты, список сессий. Кнопка ↻ обновляет лимиты вручную — не чаще раза в минуту, время данных в подсказке. Рядом — вкладка чата с тем же списком по кнопке sessions.

Настройки

разделы — страницыживая страница

Кнопка ⚙ в заголовке боковой панели открывает вкладку настроек — форму над настройками VS Code (agentura.*, раздел «Пользователь»): меняется сразу, рядом — «в настройках VS Code» и settings.json. Разделы теперь отдельные страницы, а не якоря одной ленты: слева пять вкладок (стрелки ↑↓ тоже переключают), открытый раздел запоминается. Шесть старых разделов сведены в пять: «Новая сессия» (разрешения + модель), «Контекст и лимиты», «Боковая панель», «Внешний вид» (лента, шрифты и размер ленты, язык), «Движок». В узком сплите вкладки идут полосой над страницей.
