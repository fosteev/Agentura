# Прототип интерфейса Agentura

Статический HTML/CSS/JS без сборки: открывается двойным кликом по `index.html`.
Направление — «HUD» (выбор владельца 30.09.2026): приборы в шапке, моноширинный
журнал, ход и агенты во вкладках (узкая вкладка ~380 px) или панелью справа (~900 px).
Чат живёт только во вкладке редактора; боковая панель VS Code — аккаунт, лимиты и список
сессий (экран `sessions`).

## Состав

| Путь | Что это |
|---|---|
| `index.html` | оглавление экранов и состояний |
| `screens/*.html` | экраны MVP, одна сквозная сессия («мигание счётчика талонов» в `queue-board`, 30.09, 14:41–14:56) |
| `shared/tokens.css` | переменные `--vscode-*` с запасными значениями Dark Modern / Light Modern, цвета порогов и статусов |
| `shared/hud.css`, `shared/hud.js` | стили направления и переключение вкладок чат / ход / агенты |
| `shared/preview.css`, `shared/preview.js` | обёртка предпросмотра в браузере: переключатели темы и ширины; к webview не относится |
| `shared/sidebar.js` | боковая панель VS Code (аккаунт, лимиты, сессии) в режиме «боковая панель + вкладка»; состояние берётся из `data-sidebar` на экране |
| `directions/` | этап 2.1: три направления главного экрана (архив, выбрано третье) |

Пороги контекста в прототипе: 120k (жёлтый), 150k (оранжевый), 200k (красный, автосжатие) —
значения по умолчанию из A1, настраиваются пользователем.

## Фича → экран

Строки MVP из `docs/features.md`. «Движок» — фича работает без интерфейса и экрана не получает.

## Зафиксировано / открыто

Прототип утверждён владельцем 30.09.2026, тег `prototype-v1`.

**Зафиксировано**
- Направление HUD: приборы в шапке (число контекста + 20 блоков по 10k с порогами, кэш-таймер и доля попаданий, два лимита с временем сброса), моноширинная лента-журнал, строки инструментов `▸ op · что · результат · время`, панель «ход» и «агенты» справа (в узкой вкладке — вкладками).
- Чат живёт только во вкладке редактора. Боковая панель VS Code — аккаунт и лимиты, список сессий (статус, ходы, стоимость, токены), «новая сессия».
- Карточки запросов к пользователю единого вида (`.ask`): разрешение на команду, разрешение на правку с предпросмотром и входом в нативный дифф, вопрос агента с вариантами, план с четырьмя решениями, ошибка движка, лимит.
- Системные строки ленты без карточки: компакция, коммит, смена режима, решение по плану, ход не начат.
- Поле ввода: `$`-строка, под ней режим · модель · effort; меню «/», «@», «+», режим, модель/effort/thinking, история — как на экране `input`.
- Токены `shared/tokens.css` и стили `shared/hud.css` переносятся в webview расширения как есть.

**Открыто (решить на реализации)**

- Значения по умолчанию порогов контекста (120k / 150k) и окно 200k — уточнить по данным модели из SDK (окно может быть 1M).
- Источник данных для лимитов и истечения кэша — допущение, проверяется на этапе разведки SDK в roadmap реализации.

- Иконка расширения в Activity Bar и значок состояния вкладки не нарисованы.
