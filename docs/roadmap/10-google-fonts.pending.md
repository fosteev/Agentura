# Шрифты из Google Fonts — на подтверждение и ручная проверка

## Решения на подтверждение

- [архитектура] этап 1: синхронизации между окнами VS Code нет — `FileSystemWatcher` на `fonts.json` не ставим; другое окно увидит скачанный/удалённый шрифт при следующем открытии вкладки или смене настройки вида, а одновременная загрузка в двух окнах может потерять запись в манифесте (файлы на диске останутся, повторное «добавить» чинит) — редкий сценарий, вотчер вне воркспейса не проверить без живого VS Code — откатить: `vscode.workspace.createFileSystemWatcher(new RelativePattern(userFontsDir, 'fonts.json'))` → `fire()` в `UserFonts`, либо собирать манифест сканированием `<slug>/` вместо общего read-modify-write.
- [архитектура] этап 1: на диске рядом со шрифтом лежит `<slug>/face.css`, `fonts.css` склеивается из них; манифест — `[{ family, kind, files }]` без каталога и стилей — разбор css2 не хранится в манифесте — откатить: перенести `@font-face` в манифест и генерировать `fonts.css` из него (формат globalStorage ещё не выпущен, миграции не нужно).
- [архитектура] этап 1: допустимое имя семейства — только `[A-Za-z0-9][A-Za-z0-9 ._-]*` (весь каталог Google на 2026-10-04 подходит), прочие из каталога скрываются — иначе имя из сети попадает в путь `rm -r` и в `fonts.css` — откатить: расширить `FAMILY_RE` в `src/extension/googleFonts.ts` и хранить имя папки в манифесте.
- [скоуп] этап 1: ✕ удаляет скачанный шрифт сразу, без подтверждения; удаление выбранного шрифта настройку не трогает (стек падает на шрифт VS Code) — по плану, повторная загрузка дешёвая — откатить: `showWarningMessage` с модальным подтверждением в команде `agentura.removeGoogleFont`.
- [скоуп] этап 1: в QuickPick из палитры — все семейства, из кнопки «интерфейс» — всё, кроме `Monospace`, из «код» — только `Monospace`, из «панели» — все; «Применить» из палитры ставит интерфейс или код по категории — так в плане, фиксирую для явного «ок» — откатить: фильтр в `addGoogleFont` (`src/extension/googleFontsCommand.ts`).

## Проверить руками

Сборка: `npm run build`, затем F5 (Extension Development Host) или установить vsix.

1. Палитра → «Agentura: Add Google Font…»: QuickPick открывается сразу со спиннером, через 1–3 с — список по популярности; у семейств с кириллицей в описании «кириллица»; поиск по категории («Monospace») работает.
2. Выбрать «Onest» → уведомление «Скачиваю Onest…», затем «Шрифт Onest скачан…» с кнопкой «Применить». Нажать — шрифт интерфейса во всех открытых вкладках (чат, боковая панель, настройки) сменился на Onest, без перезагрузки окна.
3. ⚙ → «Вид»: в карточках интерфейса есть Onest (после встроенных), карточка нарисована Onest. Под карточками интерфейса, панелей и кода — кнопка «Добавить из Google Fonts…»; у кода QuickPick показывает только моноширинные, у панелей — все; «Применить» из панелей меняет шрифт панелей.
4. Навести на карточку Onest — в правом верхнем углу ✕, не перекрывает имя и не ломает сетку (проверить и в узкой панели). Tab до ✕ — видна рамка; стрелки на ✕ не переключают выбор; Enter — шрифт пропадает из карточек во всех вкладках, фокус остаётся на выбранной карточке.
5. Повторно открыть QuickPick: скачанный — с ✓ и «скачан»; выбор скачанного — сразу «Применить», без загрузки.
6. DevTools webview (Developer: Open Webview Developer Tools): в консоли нет ошибок CSP; `<link id="user-fonts">` с `?v=…`, после второй загрузки `v` меняется; woff2 грузятся с `vscode-resource`.
7. Отключить сеть, выполнить команду: при кэше каталога (до 7 дней) — список есть; загрузка нового — ошибка «Не удалось скачать …», в логе Agentura — предупреждение.
8. Два окна VS Code: скачать шрифт в одном — во втором он появится в карточках после переоткрытия вкладки настроек (так задумано, см. решения).
