# 18 — лимиты движков: ручная проверка

Собрать (`npm run build`), F5 или установить vsix; нужны установленные `codex` и/или `agy`.

- [ ] Боковая панель: при установленных Codex/agy секция «Аккаунты и лимиты» показывает три движка, по умолчанию
      раскрыт движок активной вкладки (переключи вкладку Claude ↔ Codex — раскрытый меняется).
- [ ] Цифры Codex совпадают с `codex /status` (5h и Weekly), Antigravity — с `agy /usage` (израсходовано = 100 − остаток).
- [ ] ⚙ → «Боковая панель» → «Лимиты движков»: перебрать пять вариантов; команда «Agentura: Вид лимитов…» делает то же.
- [ ] Вариант E: клик по мини-шкалам открывает всплывашку, Esc / клик мимо закрывает.
- [ ] «Вид верха» = плотно → лимиты в заголовке при любом варианте.
- [ ] Светлая тема: метки C / X / G и шкалы читаются.
- [ ] Выйти из Codex (`codex logout`), ↻ через минуту → «не вошли · войти»; «войти» открывает терминал с `codex login`.
- [ ] Без Codex и agy (переименовать бинарники или пустые пути в настройках) — секция как раньше, только Claude.
