# Вкладка «изменения» — на подтверждение и ручная проверка

## Решения на подтверждение

- [скоуп] этап 1: проверки определяются по программе простой команды (раннер + скрипт `test/lint/check/typecheck/e2e` или `vitest/jest/pytest/mocha/eslint/tsc/playwright test`), а не регэкспом по любому слову; фоновые Bash (`run_in_background`) в проверки не попадают; прерванная проверка показывается ✗ — регэксп ловил `ls test/`, `git commit -m "fix test"`, фоновый запуск давал ложный «✓ 0 с» — откат: `isCheckCommand` в `src/webview/changesView.ts` вернуть к регэкспу, убрать пропуск `run_in_background`.
- [архитектура] этап 1: хост хранит на всю сессию id→файл всех применённых правок и стороны первой/последней целой правки каждого файла (`editFiles`, `fileSpans` в `chatController.ts`; память — две копии на изменённый файл) — иначе дифф «за сессию» после 50 правок молча показывал хвост — откат: убрать обе карты, склейка только по `edits` (лимит `MAX_EDITS`).

## Проверить руками

- этап 1 · VS Code (F5 / установленный vsix), чат в широком режиме, сессия, где агент правил 2+ файла в разных папках и гонял `npm test` / `npm run check`: справа вкладка «изменения» активна по умолчанию; файлы сгруппированы по папкам, у каждого +/− и номера ходов; у созданного Write — пометка «новый»; внизу «проверки» с ✓/✗, временем и номером хода; бейдж вкладки и полосы = число файлов, пульсирует во время правки.
- этап 1 · там же: клик по файлу — открывается обычный дифф в соседней группе (слева — до первой правки, справа — после последней); «дифф всего» — мульти-дифф VS Code со всеми файлами, тоже в соседней группе, **не поверх вкладки чата**; файлы с одинаковым именем в разных папках — отдельными секциями с верным содержимым.
- этап 1 · переключатель «сессия | ход N»: в «ход» — только правки последнего хода, пусто — «В этом ходе правок нет»; выбор переживает перезагрузку окна. Отправить сообщение, пока агент работает (в очередь): номер хода и список не должны прыгнуть до начала нового хода.
- этап 1 · узкий режим (панель узкая) — вкладка «изменения» в шапке с бейджем; свёрнутая полоса — значок ± с бейджем, клик открывает панель на «изменениях». Окно, где раньше была открыта вкладка «ход», после обновления открывается на «изменениях».
- этап 1 · после перезапуска VS Code и открытия старой сессии из истории: «изменения» заполнены, клик по файлу и «дифф всего» открывают дифф (из восстановленной истории).
