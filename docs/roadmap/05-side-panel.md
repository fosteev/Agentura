# Правая панель вкладки чата: ресайз, скрытие, вкладки

> Статус: этапы 1–2 приняты 2026-10-02 (вариант B — полоса; этап 2 смержен в main `0224352`, галерея v15) · остался F5 владельца · создан 2026-10-02 по запросу владельца.
> Формат — этап → исполнитель → приёмка. Дизайн владелец принимает только картинками в галерее-артефакте.

## Цель

В широком режиме (≥ 700 px) правая панель вкладки чата:
1. тянется мышкой за левый край;
2. сворачивается и разворачивается одной кнопкой;
3. «ход» и «агенты» — отдельные вкладки на всю высоту панели, а не два блока друг под другом.

## Решения владельца (2026-10-02)

- Вкладки панели: `ход | агенты`. «предыдущий» ход — внутри «ход»; итог «за сессию» — внутри «агенты». Бейджи — как у
  вкладок узкого режима (`turnBadge`, `agentBadge`).
- Автоперехода на «агенты» при старте субагентов нет — только бейдж.
- Ширина, «свёрнуто» и активная вкладка панели — **свои у каждой вкладки чата** (состояние webview `setState`), новая
  вкладка — 300 px, развёрнута, «ход».
- Вид свёрнутой панели — **вариант B «полоса 32 px»** (выбран по галерее v14, 2026-10-02): значки «ход» и «агенты» с
  бейджами, внизу «показать панель»; клик по значку разворачивает панель на этой вкладке. Вариант A удаляется.
- Размен принят: решение этапа 1 roadmap 0.2 («агенты» прижаты к низу, видны вместе с ходом) отменяется — за живыми
  субагентами следят по бейджу.
