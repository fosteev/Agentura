# Тултипы и язык интерфейса — на подтверждение владельцу

Файл к `07-tooltips-i18n.md`: решения, принятые без владельца, и проверки, которые делает только он.

## Решения на подтверждение

- [скоуп] «Системный язык» = язык интерфейса VS Code (`vscode.env.language`), а не macOS: ru* → русский, остальное →
  английский — откат: читать `Intl.DateTimeFormat().resolvedOptions().locale` хоста (язык ОС, но ненадёжно при
  запуске из Dock).
- [скоуп] Смена `agentura.language` применяется после перезагрузки окна (уведомление с кнопкой), без живого
  перерендера — откат: перерендер всех webview на смену настройки (риск потерять стейт идущего хода).
- [скоуп] Заголовки команд и описания настроек в Settings UI следуют языку VS Code, не `agentura.language` —
  ограничение API VS Code, обойти нельзя.
- [скоуп] Не переводятся: промпт модели, логи, debug-панель, ответы движка.
