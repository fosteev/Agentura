# Тултипы и язык интерфейса — на подтверждение владельцу

Файл к `07-tooltips-i18n.md`: решения, принятые без владельца, и проверки, которые делает только он.

## Решения на подтверждение

- [скоуп] «Системный язык» = язык интерфейса VS Code (`vscode.env.language`), а не macOS: ru* → русский, остальное →
  английский — откат: читать `Intl.DateTimeFormat().resolvedOptions().locale` хоста (язык ОС, но ненадёжно при
  запуске из Dock).
- [скоуп] Смена `agentura.language` применяется после перезагрузки окна (уведомление с кнопкой), без живого
  перерендера — откат: перерендер всех webview на смену настройки (риск потерять стейт идущего хода).
- [скоуп] Заголовки команд и описания настроек в Settings UI следуют языку VS Code, не `agentura.language` —
  ограничение API VS Code, обойти нельзя.
- [скоуп] Не переводятся: промпт модели, логи, debug-панель, ответы движка.

## Проверить руками

Все — F5 (Extension Development Host) или переустановленный `.vsix`.

- Тултипы: навести на ⚙, ↻, ☰/≡/≣ в боковой панели, на «скрыть панель», «enter ↵», stop во время хода — подсказка
  появляется через ~0,5 с, соседние — сразу; у ↻ две строки (вторая бледнее); у отправки плашка `Enter`. У края
  окна не обрезается, у нижнего края — над кнопкой. Светлая и тёмная тема читаются.
- Тултипы на неактивных кнопках (например, Codex/Gemini «скоро» в меню агента, «сжать» без сессии): Chrome может
  не слать события наведения на `disabled` — если подсказки нет, сказать (раньше системный `title` там был).
- Tab по кнопкам — подсказка у сфокусированной; Esc прячет.
- ⚙ → «Вид» → «Язык интерфейса» → English: уведомление с кнопкой Reload; после перезагрузки чат, боковая панель и
  настройки по-английски (даты `Mon`, `September 23`, `2 h 05 min`); ошибки в полях настроек — по-английски.
- `auto` при английском VS Code — английский; при русском — русский. Названия команд в палитре (`Agentura: …`)
  следуют языку VS Code, а не настройке — так задумано.
- Качество английских формулировок — глазами; что режет — списком.
