# Записи запуска дочерних агентов Codex

Маршрут M. Реализовать в текущей сессии без коммита и установки расширения.

## Задача и решения

Показать добровольно записанное родителем задание, когда Codex скрывает стартовый промпт.
Dynamic tool `agentura_record_agent_launch` регистрируется при создании нового треда.
Описание инструмента требует записать точный текст и параметры перед `spawn_agent`.
Не заменять developer instructions пользователя. Возобновлённые старые треды не получают новый инструмент.

Хранить записи вне проекта в `~/.local/share/agentura/agent-launches`, с приватными правами.
Связь: родительский thread ID + turn ID + точный `/root/task_name` из `subAgentActivity`.
Повторы одного вызова идемпотентны; конфликтующие записи отклоняются. Не угадывать по порядку запуска.
Источник и заявленные параметры отделены от метаданных Codex. Это не подтверждение фактического запроса.
История восстанавливает записи даже без доступного дочернего треда.

## Подтверждённые точки входа

- `src/agent/codex/adapter.ts`: openThread, item/tool/call, emit, loadHistory.
- `src/agent/codex/jiraTools.ts`: действующий контракт host dynamic tools.
- `src/agent/types.ts`, `src/webview/hudState.ts`: события и модель карточки.
- `src/webview/agentViews.ts`, `agentsView.ts`, `components/SidePanes.tsx`: детали панели и графа.

## DoD

- Инструмент валидирует источник, ход и аргументы, подтверждает только сохранённую запись.
- Привязка двух детей при обратном порядке событий; чужой ход/вложенный путь не совпадают.
- История после нового экземпляра адаптера сохраняет промпт и provenance.
- Все виды карточки показывают источник, заданные модель/effort и контекст.
- Целевые тесты, typecheck, lint, build; полный suite при отсутствии внешних блокеров.
- Живое выполнение моделью и визуальная проверка установленного расширения отмечаются отдельно.
