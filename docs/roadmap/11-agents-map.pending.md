## Проверить руками

### Этап 1 — виды панели (принят 2026-10-04)

Где: VS Code с собранным расширением (ветка `stage-1-agents-map-views` или main после мержа), вкладка чата с сессией,
где работали 3–4 субагента (часть идёт) и фоновый shell; правая панель → вкладка «агенты».

- [ ] **Дерево** (`"agentura.agents.view": "tree"`): ход раскрыт, линии веток ровные, фоновые — пунктирной веткой;
      клик по агенту раскрывает под ним промпт (3 строки), последние 3 вызова, «транскрипт» / «■ остановить»; клик по
      другому — раскрытие переезжает. Охват «сессия»: прошлые ходы свёрнуты в строку `▸ ход N · HH:MM · Explore ×2 ✓✓ · 18.2k`,
      клик раскрывает.
- [ ] **Дорожки** (`lanes`): ось с 3–5 метками, у основного — полосы рассуждения/инструментов и штриховка «ждёт»,
      у агентов — полосы с засечками вызовов, у идущих — синяя линия «сейчас», которая едет раз в секунду; клик по
      дорожке подсвечивает её и показывает блок агента ниже. Сессия на десятки минут / часы — метки `1h`, `1h30`, не каша.
- [ ] **Карточки** (`cards`): идущие сверху, потом упавшие, потом готовые; у идущей — живая строка и полоска вызовов,
      у упавшей — текст ошибки и «лог», у готовой — выдержка итога и «итог ≈0.4k → в основной»; «■ стоп» останавливает агента.
- [ ] **Ширина панели** 220 / 300 / 600 px для всех трёх видов: ничего не вылезает за край, при ≤ 280 px подпись дорожки
      уже (80 px), имена режутся многоточием.
- [ ] **Узкое окно** (< 700 px, панель вкладкой, не сбоку): у дерева нижний хвост вертикальной линии ветки
      маскируется фоном `--bg-side` — проверить, что на фоне вкладки не видно светлой/тёмной «заплатки».
- [ ] **Remote SSH / WSL** (если пользуешься): у живых агентов на дорожках нет ложных «↤» в начале хода.
- [ ] **Светлая тема** (Light+): штриховка «ждёт», засечки, полосы и рамки карточек видны.
- [ ] **Список** (`list`, по умолчанию): выглядит и работает как до этапа (с этапа 2 — плюс кнопка ↗ «граф»).
- [ ] **⚙ → «Вид» → «Карта агентов»**: пять карточек с живыми миниатюрами (для `graph` с этапа 2 — граф), выбор пишет настройку.
- [ ] **Команда** «Agentura: Agents View…» / «Вид карты агентов…»: QuickPick из пяти с ✓ у текущего, выбор меняет вид
      открытой вкладки сразу.
- [ ] **settings.json на лету**: поменять `agentura.agents.view` при открытой вкладке чата — вид меняется без переоткрытия;
      охват «ход/сессия» каждого вида переживает перезагрузку окна.


### Этап 2 — граф во вкладке редактора (принят 2026-10-04)

Где: VS Code с собранным расширением (ветка `stage-2-agents-graph` или main после мержа), вкладка чата с сессией, где
идут 3–4 субагента (один вложенный) и фоновый shell; `"agentura.agents.view": "graph"`, потом любой другой вид.

- [ ] **Открыть граф**: ↗ «граф» в панели агентов (в каждом из пяти видов) — рядом с чатом (`Beside`) открывается вкладка
      «Агенты · <название сессии>»; повторный ↗ не плодит вкладки, а показывает ту же.
- [ ] **При `graph`**: «карта агентов», строка агента, «итог»/«лог» в ленте открывают граф с этим агентом выбранным;
      клик по агенту в списке панели — только выбор в списке (решение `[скоуп]`).
- [ ] **Вёрстка** (тёмная и светлая темы): основной слева по центру, агенты колонкой справа, вложенный — третьей колонкой,
      фоновые — ниже пунктиром; рёбра не режутся, подписи `↗ ≈… · ↙ ≈…` у начала ребра, сетка точек на фоне, легенда внизу.
- [ ] **Живое обновление**: пока агенты идут — статусы, счётчики и таймеры меняются (таймеры раз в секунду), ход отмечен
      «идёт»; агент закончился — ✓ и итог в деталях.
- [ ] **Детали справа**: промпт, вызовы, итог; «■ стоп» останавливает агента, «транскрипт» открывает его лог; «■» у идущего
      фонового shell останавливает его.
- [ ] **Узкая вкладка** (< 640 px): детали уходят под холст; **много агентов** (8+): холст прокручивается, ничего не налезает.
- [ ] **Скрыть и показать** вкладку графа (перекрыть другой вкладкой в той же группе) и кликнуть агента в ленте — граф
      показывается с этим агентом выбранным, данные свежие.
- [ ] **Сменить сессию во вкладке чата** (новая / возобновить другую) при открытом графе — граф показывает новую сессию,
      заголовок меняется, выбор агента сброшен.
- [ ] **Закрыть чат** — его граф закрывается. Закрыть граф — чат работает дальше, ↗ открывает граф заново.
- [ ] **Reload Window** с открытыми чатом и графом — граф возвращается к своему чату и через секунду показывает данные;
      чат скрыт (другая вкладка поверх) — граф пишет «Ждём данные из вкладки чата…», пока чат не показать; две вкладки
      чата одной сессии, у каждой граф — после перезагрузки у каждой снова по графу.
- [ ] **⚙ → «Вид» → «Карта агентов»**: карточка `graph` — уменьшенный настоящий граф (без деталей), остальные карточки
      и страница настроек не изменились (стили графа не протекли).
