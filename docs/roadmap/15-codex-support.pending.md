## Проверить руками

- **Этап 1 — настройки.** Где: Settings (Cmd+,) → поиск `agentura`. Что сделать: найти `Codex Executable` и `Default Provider`; во вкладке Workspace попробовать задать `agentura.codexExecutable`. Что увидеть: обе настройки есть, описания на языке интерфейса VS Code (en/ru); `Codex Executable` и `Default Provider` в Workspace недоступны/помечены как применяемые только в User; `Default Provider` — выпадающий список Claude Code / Codex, по умолчанию Claude Code.
- **Этап 1 — восстановление вкладок со старой версии.** Где: окно проекта, где на 0.4.0 были открыты 2+ Claude-сессии. Что сделать: поставить сборку с этапом 1, перезагрузить окно (Developer: Reload Window). Что увидеть: те же вкладки с теми же сессиями, клик по сессии в боковой панели открывает/показывает её вкладку, как раньше; ещё одна перезагрузка — вкладки на месте (память переписана в новом формате).
