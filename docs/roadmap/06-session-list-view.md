## Цель

Список сессий в боковой панели занимает меньше места по вертикали, а пользователь сам выбирает, сколько строк на
сессию и какие колонки справа показывать. Всё через настройки VS Code `agentura.sessionList.*`, без перезапуска.

## Решения владельца (2026-10-02)

- Из пяти вариантов прототипа (как сейчас / A / B / C / D) в настройку пошли три вида: `detailed` (две строки, как
  было), `compact` (по умолчанию: одна строка, у текущей, идущей, ждущей ответа и упавшей — две), `dense` (всё в одну).
  Цена в строке (B) и отказ от заголовков дней (D) — не делаем.
- Вид переключается и кнопкой в заголовке секции «Сессии», по кругу ☰ → ≡ → ≣, как переключатель вида в проводнике
  VS Code. Настоящего дерева (сворачиваемых дней) нет.
- Контекст сессии колонкой справа, `173k ctx` (комментарий в галерее v17). Колонки контекста и времени —
  отдельные настройки, по умолчанию включены, фиксированной ширины, выровнены вправо у всех строк.
- Контекст колонкой во второй строке не повторяется; ходы, цена и контекст всегда есть в подсказке строки.

## Контракт

| Ключ | Тип | По умолчанию | Что |
|---|---|---|---|
| `agentura.sessionList.view` | `detailed` \| `compact` \| `dense` | `compact` | строк на сессию |
| `agentura.sessionList.context` | boolean | `true` | колонка `173k ctx` |
| `agentura.sessionList.time` | boolean | `true` | колонка времени (`сейчас`, `13:05`, `вт`, `25.09`) |

- Ключ вида — `sessionList.view`, а не `sessionList`: VS Code хранит настройки вложенными объектами, строка и
  `sessionList.*` под одним именем конфликтуют.
- Хост → боковая панель: `{ type: 'sidebar.view'; view; context; time }` на `ready` и при
  `onDidChangeConfiguration('agentura.sessionList')`. Боковая панель → хост: `settings.set` с ключом
  `sessionList.view` (кнопка); хост пишет в Global и в ответ шлёт фактическое значение (если вид перекрыт настройкой
  рабочей папки, кнопка вернётся к нему).
- Вёрстка — атрибуты `data-list`, `data-ctx`, `data-time` на `.sidebar`, правила в конце `media/hud.css`
  (= `prototype/shared/hud.css`, держатся одинаковыми).

## Риски и открытые вопросы

- Значки ☰ ≡ ≣ — символы шрифта, не codicons; в некоторых темах/шрифтах могут выглядеть одинаково. Узнаем на F5;
  запасной вариант — codicons `list-flat` / `list-tree` (потребует подключить шрифт codicons в webview).
- `min-width` колонок подобран под 11px моно/системный шрифт (`8ch` под `173k ctx` и `1.2M ctx`, 42px под «сейчас»).
  Если в теме VS Code шрифт шире — колонки разъедутся у отдельных строк. Проверка — на F5.
- Ширина боковой панели узкая (< 260 px): при включённых обеих колонках название режется сильно. Допущение: ок,
  колонки выключаются в настройках.
- В «компактном» виде важные строки двухстрочные — порядок важности (текущая, идущая, ждёт ответа, ошибка) зашит в
  CSS; если владелец захочет иначе — правка одного селектора.
