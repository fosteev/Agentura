## Замечания владельца (дегустация 0.1)

Шаблон строки: `- [ ] [P1|P2|P3] [чат|приборы|сессии|разрешения|упаковка|…] что не так → как ожидалось (сессия/шаги, если есть)`

- [x] [P2] [приборы] (перенесено в этап 1 roadmap 04, сделано 2026-10-01) Широкая вкладка (900/full), правая панель: «ход» — длинная простыня, и блок «агенты» с
  итогами сессии уезжает вниз, к нему приходится листать всю панель → «агенты» (вместе с «за сессию») всегда
  прижат к низу панели, а «ход» над ним занимает остаток высоты и скроллится сам. Сейчас скроллится весь
  `.pane.side` (`media/hud.css`, правила `html[data-width="900"|"full"] .pane.side`). Как чинить: `.pane.side` —
  `display: flex; flex-direction: column; overflow: hidden`, tabpane «ход» — `flex: 1; min-height: 0;
  overflow: auto` с прилипанием к низу во время хода (как лента чата), tabpane «агенты» — `flex: none` с
  `max-height` ≈ 50% и своим скроллом на случай десятка субагентов. Узкий режим (вкладки `чат | ход | агенты`)
  не трогать. Перенести в прототип (`prototype/shared/hud.css`) и показать картинкой (сессия 01.10, скриншот)

## Технический долг (из приёмок и рисков)

### Производительность и данные
- [ ] Список сессий во время хода синхронно перечитывает активный `.jsonl` целиком (итоги + `requestExtras`) на потоке хоста не реже раза в 4 с — на сессиях в десятки МБ подвисания. Лечение: разбор по смещению или пропуск итогов живой сессии с `total_cost_usd` движка (этап 6)
- [ ] `transcriptExtras` держит строки файла в памяти целиком на `resume`/пересеве (этап 6)
- [ ] Пересев при идущем ходе может потерять дельты, пришедшие за время чтения транскрипта (редко: «Reload Webviews» посреди ответа) (этап 6)
- [ ] Ход с моделью без цены выпадает из `totalCostUsd` истории без пометки (этап 6)
- [ ] Синтезированный `turn.result` всегда `ok: true` — ошибка API в истории показана отдельной строкой `error` (этап 6)
- [ ] Переименование сессии, у которой идёт ход, может быть перезаписано названием из памяти CLI — не проверялось (этап 6)
- [ ] Формат транскриптов внутренний: фикстуры Agentmeter и сверка `scripts/sessions-verify.mjs` при каждом обновлении CLI/SDK (риск)
- [ ] SDK 0.3.x меняется: версия зафиксирована точно, обновлять отдельным коммитом с прогоном фикстур этапа 0 (риск)
