# 17 — Remote Control: на подтверждение и ручные проверки

## Решения на подтверждение

- [ ] `[скоуп]` Включение посреди сессии не повторяет историю на claude.ai — видно только то, что после включения.
- [ ] `[архитектура]` Мост на alpha-API SDK (`@anthropic-ai/claude-agent-sdk/bridge`): ломается без смены мажора —
      при обновлении SDK прогонять живую проверку ниже.

- [ ] `[скоуп]` v1: запросы разрешений, открытые до включения моста или во время переподключения, на claude.ai не уходят.
- [ ] `[скоуп]` v1: одобрение правки с телефона не сохраняет грязный буфер VS Code (`saveBeforeEdit` — только у ленты).

## Ручные проверки (владелец, телефон)

- [ ] Вкладка Claude → «rc» → «вкл»: в ленте строка с ссылкой, в шапке «● remote»; сессия видна в claude.ai/code и в приложении.
- [ ] Ход из VS Code виден на телефоне (текст, инструменты), спиннер гаснет по концу хода.
- [ ] Сообщение с телефона уходит в работу; в ленте помечено «с телефона».
- [ ] Запрос разрешения: ответ с телефона закрывает карточку в VS Code, и наоборот.
- [ ] Вопрос (AskUserQuestion) и план с телефона — карточки рисуются, ответ доходит (форма `can_use_tool` — догадка).
- [ ] Стоп с телефона прерывает ход.
- [ ] Закрыть вкладку → сессия на claude.ai перестаёт отвечать, ошибок в журнале нет.
- [ ] Настройка «Remote Control для новых сессий» → новая вкладка сразу подключается.
