# Вкладка «git» — проверить руками

> Roadmap: `12-git-tab.md`. Отмечай `[x]`, что проверено; что не так — строкой под пунктом.

## Этапы 1–2: вкладка для одного репозитория (2026-10-04)

- [ ] F5 / установленный vsix, папка — один git-репозиторий с изменениями: вкладка `изменения | git | агенты`, бейдж —
  число изменённых файлов; в свёрнутой полосе — значок git с бейджем
- [ ] тёмная и светлая темы; ширина панели 220 / 300 / 600 px — ничего не налезает, длинные имена режутся «…»
- [ ] «путь» / «дерево» переключаются и запоминаются после перезагрузки окна; чип «● агент N» оставляет только файлы,
  которые правил агент в этой сессии
- [ ] клик по файлу — дифф (вне индекса: индекс ↔ файл; в индексе: HEAD ↔ индекс; новый — сам файл)
- [ ] «+» / «−» у файла, «+ все в индекс» / «− все» — файл переезжает между секциями, +/− цифры верные
- [ ] «отменить изменения» — модальное подтверждение; «Отмена» ничего не трогает; неотслеживаемый — «удалить»
- [ ] коммит: заголовок + описание, счётчик 72, ⌘/Ctrl+Enter, amend, «и push»; после коммита поле очищено, коммит в
  «последних», неотправленные — синим с ↑
- [ ] ветка ▾ — QuickPick веток, «Создать ветку…»; fetch / pull / push; новая ветка — «не опубликована» → push публикует
- [ ] git выключен (`"git.enabled": false`) — «git недоступен» с причиной; папка без репо — «Репозиториев нет» с подсказкой
