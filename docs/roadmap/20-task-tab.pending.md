# 20 — ручные проверки и решения на подтверждение

Пополняется приёмкой каждого этапа. Отмечает владелец.

## Этап 2 (2026-10-09) — вкладка «задача» в живом VS Code

- [ ] Чат по задаче: в полосе задачи «чат | задача»; в правой панели и в полосе-рейле «задачи» больше нет.
- [ ] «задача»: правая панель пропадает, карточка во всю ширину, поля справа; узкое окно (< 720 px) — поля под заголовком.
- [ ] Описание и комментарии с форматированием; ссылка на другую задачу (`/browse/…`) открывается в браузере — и для
      Jiraffe, и для своего подключения.
- [ ] Статус ▾: меню переходов, переход меняет статус; переход с обязательными полями неактивен с подсказкой.
- [ ] Комментарий: Cmd+Enter отправляет, кнопка заблокирована до ответа, комментарий появляется в списке.
- [ ] Ворклог: `1h 30m` уходит, время в колонке «Время» растёт.
- [ ] «↳ в чат» у карточки — к полю ввода прикладывается `<KEY>.md`, вкладка переключается на «чат», фокус в поле;
      у комментария (при наведении) — текст комментария в поле.
- [ ] Во время хода на «задаче»: на «чате» спиннер и счётчик новых; разрешение/вопрос — жёлтая точка и тост «к чату».
- [ ] Esc в поле комментария не останавливает ход агента.
- [ ] Переключение «чат ↔ задача» не сбрасывает прокрутку ленты и черновик в поле ввода.
