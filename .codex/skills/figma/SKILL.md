# Figma

Если доступны Figma MCP-инструменты, используй их и следуй подключённым Figma-скиллам. При отсутствии MCP можно запросить Figma REST API с `FIGMA_TOKEN`; токен не печатай и не коммить. Снимок/JSON — источник чисел для padding, типографики, цветов и эффектов; картинка нужна для сверки композиции.

Не выдавай визуальное сходство за pixel-perfect без проверяемого рендера. Перед кодом сопоставь полученные токены с существующей дизайн-системой проекта, чтобы не плодить локальные значения.
