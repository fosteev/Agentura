# Roadmap

Создавай `docs/roadmap/<nn>-<slug>.md`, если проект не задаёт другое место. До записи прочитай правила проекта и докажи точки входа поиском.

Файл должен содержать: цель и границы, текущее состояние, решения и открытые вопросы, этапы в порядке зависимостей, для каждого — чекбоксы, изменяемые файлы/контракты, DoD, проверки, риски и ручные проверки. После этапов добавь самодостаточные промты следующей сессии.

Правила: `[x]` — только после проверки; один этап не смешивает независимые изменения; backend/API, требующие другой команды, описывай отдельной задачей; не придумывай контракты. Добавь краткий статус-баннер и как продолжить с первого незавершённого этапа.
