# Логотипы в прототипе

Локальные копии: экран работает без запросов к сторонним сайтам.
Получены 2026-11-06; используются для обозначения соответствующих продуктов.

- `claude.svg`: Simple Icons v14, https://cdn.jsdelivr.net/npm/simple-icons@v14/icons/claude.svg (знак Claude / Anthropic).
- `openai.svg`: Simple Icons v14, https://cdn.jsdelivr.net/npm/simple-icons@v14/icons/openai.svg (знак OpenAI для Codex).
- `cursor.svg`: https://cursor.com/marketing-static/favicon-light.svg — официальный сайт Cursor, https://cursor.com/brand.
- `antigravity.svg`: https://antigravity.google/favicon.svg — официальный сайт Google Antigravity.

Simple Icons: https://github.com/simple-icons/simple-icons/tree/14.0.0 — CC0;
товарные знаки принадлежат соответствующим владельцам. SVG не перерисованы.

Варианты для нативных вкладок: `claude-color.svg` — тот же знак с заливкой #D97757; `openai-dark.svg` — белая заливка для тёмной темы. Геометрия исходных SVG сохранена.
